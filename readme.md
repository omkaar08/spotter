# Freight Rate Prediction Challenge — Solution Implementation

This repository contains a complete, reproducible machine learning solution for the **Spotter AI Freight Rate Prediction Challenge**. The goal is to predict spot rates (`posted_rate` in USD) for truckload freight shipments.

---

## 🛠️ Environment Setup & Installation

Ensure Python 3.10+ is installed. Install all dependencies from `requirements.txt`:

```bash
python -m pip install -r requirements.txt
```

### Required Dependencies
- `pandas >= 2.0`
- `numpy >= 1.26`
- `scikit-learn >= 1.4`
- `lightgbm >= 4.0`
- `xgboost >= 2.0`
- `catboost >= 1.2`
- `matplotlib >= 3.8`
- `seaborn >= 0.13`
- `reportlab >= 4.0`

---

## 🚀 Quickstart & Pipeline Execution

To run the complete end-to-end pipeline from data auditing to model training, prediction generation, and official scoring:

### Step 1: Run Data Validation & Audit
```bash
python src/data_validation.py
```

### Step 2: Train Models & Run Out-Of-Time Validation
```bash
python src/train.py
```
*Trains Ridge, Random Forest, LightGBM, XGBoost, CatBoost, and the Spotter Weighted Ensemble on temporal Out-Of-Time (OOT) split (Jan–Aug 2025 Train -> Sept–Oct 2025 Validation). Saves model artifacts to `models/` and evaluation results to `outputs/model_comparison.csv`.*

### Step 3: Generate Predictions & Validate with Scorer
```bash
python src/predict.py
```
*Generates predictions for `validation_predictions.csv` (12,000 loads) and `data/december_chart_inputs.csv` (31 loads), then executes `score.py` automatically.*

### Step 4: Generate Evaluation Plots & Residual Diagnostics
```bash
python src/evaluate.py
```
*Produces feature importance rankings (`outputs/feature_importances.png`), residual plots (`outputs/residual_analysis.png`), and segment error reports (`outputs/evaluation_report.txt`).*

### Step 5: Build PDF Report
```bash
python generate_pdf_report.py
```
*Compiles `Spotter_ML_Assessment_Report.pdf` with embedded scorer chart `candidate_december.png` and diagnostic charts.*
